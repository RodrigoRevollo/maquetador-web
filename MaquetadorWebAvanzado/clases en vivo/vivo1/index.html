Tipos de selectores

Los selectores son patrones utilizados para seleccionar elementos HTML que deseas estilizar con CSS. Existen varios tipos de selectores, cada uno con su propia sintaxis y propósito. A continuación, se presentan algunos de los tipos de selectores más comunes:

1. Selector de tipo

Selecciona todos los elementos de un tipo específico. Por ejemplo, para seleccionar todos los párrafos:

p {
    color: blue;
}

2. Selector de clase

Selecciona todos los elementos que tienen una clase específica. Se denota con un punto (.) seguido del nombre de la clase. Por ejemplo, para seleccionar todos los elementos con la clase "destacado":

.destacado {
    font-weight: bold;
}

3. Selector de ID

Selecciona un elemento único que tiene un ID específico. Se denota con una almohadilla (#) seguida del nombre del ID. Por ejemplo, para seleccionar el elemento con el ID "header":

#header {
    background-color: gray;
}

4. Selector de atributo

Selecciona elementos basados en la presencia o valor de un atributo. Por ejemplo, para seleccionar todos los enlaces que tienen el atributo "target" con el valor "_blank":

a[target="_blank"] {
    color: red;
}

5. Selector de descendiente

Selecciona elementos que son descendientes de un elemento específico. Por ejemplo, para seleccionar todos los párrafos dentro de un div:

div p {
    font-size: 14px;
}

6. Selector de hijo

Selecciona elementos que son hijos directos de un elemento específico. Por ejemplo, para seleccionar todos los párrafos que son hijos directos de un div:

div > p {
    margin-bottom: 10px;
}

7. Selector de hermano adyacente

Selecciona un elemento que es el siguiente hermano de otro elemento. Por ejemplo, para seleccionar un párrafo que sigue inmediatamente a un encabezado:

h1 + p {
    color: green;
}

8. Selector de hermano general

Selecciona todos los elementos hermanos que siguen a otro elemento. Por ejemplo, para seleccionar todos los párrafos que siguen a un encabezado:

h1 ~ p {
    color: orange;
}
