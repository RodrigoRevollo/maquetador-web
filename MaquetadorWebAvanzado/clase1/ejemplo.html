Tipos de Selectores en CSS

1. Selector de Etiqueta

Selecciona elementos HTML por su nombre de etiqueta. Ejemplo: `p { color: blue; }` selecciona todos los párrafos y les aplica el color azul.

2. Selector de ID

Selecciona un elemento HTML por su atributo ID. Ejemplo: `#miElemento { font-size: 20px; }` selecciona el elemento con el ID "miElemento" y le aplica un tamaño de fuente de 20 píxeles.

3. Selector de Clase

Selecciona elementos HTML por su atributo de clase. Ejemplo: `.miClase { background-color: yellow; }` selecciona todos los elementos con la clase "miClase" y les aplica un fondo amarillo.
